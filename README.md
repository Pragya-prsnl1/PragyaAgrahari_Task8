# Laundry Wallah - Responsive Website

This is a simple laundry service website that I made as an assignment during my web development course.

## Features

- Responsive navbar for desktop and mobile screens
- Hamburger menu icon for mobile view
- Navigation dropdown using the CSS `:focus` pseudo-class
- Hero section with text, image, and a booking button
- Hover effects on navigation links and buttons

## Technologies Used

- HTML
- CSS
- Font Awesome for the hamburger menu icon

## What I Learned

- Making a website responsive using media queries
- Using `display: none` and `display: flex`
- Positioning elements using CSS
- Using the `:focus` pseudo-class to show the mobile menu without JavaScript
- Styling navigation links and adding hover effects

## Note

This project was made for practice to improve my HTML and CSS skills.
